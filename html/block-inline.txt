Block - inline 차이
===============================================================================
구분                블록 요소(Block)            인라인 요소(inline)
-------------------------------------------------------------------------------
줄바꿈              항상 새로운 줄에서 시작,      줄바꿈 없이 텍스트 흐름에 맞춰
                   앞뒤로 자동 줄바꿈            나란히 배치
-------------------------------------------------------------------------------
width              부모요소의 너비 전체를        콘텐츠(텍스트, 이미지 등)의 
                   100% 차지                  크기만큼만 차지
-------------------------------------------------------------------------------
크기 지정           CSS로 Width, height         Width, height 속성이 적용되지 않음
(width, height)    지정 가능
-------------------------------------------------------------------------------
여백(margin,       상하좌우 모두 적용 가능        좌우는 적용되지만 상하여백은 레이아웃에
padding)                                      밀림없이 겹침 현상발생
-------------------------------------------------------------------------------
포함 관계           블록 및 인라인요소를 모두      주로 인라인요소나 텍스트만 포함 권장
                   자식으로 포함 가능            (블록 요소 포함 불가)
-------------------------------------------------------------------------------

===============================================================================
Block 태그 종류
-------------------------------------------------------------------------------
div, h1~h6, table, from, ul, ol, header, section, article, aside, footer
===============================================================================
Inline 태그 종류
-------------------------------------------------------------------------------
span, a, b, i, small, img, input, button, audio, video, sub, sup
===============================================================================
